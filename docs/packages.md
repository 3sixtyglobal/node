# Node Packages

## node-core

The `node-core` package provides the shared runtime foundation for this repository, bringing together reusable server capabilities, command tooling support, and integration patterns that can be used across services. It allows other components to build on a consistent operational base and helps keep common behaviour centralised rather than duplicated. Its role is essential for long term maintainability, because it keeps runtime concerns in one place while still allowing the platform to evolve safely. For broader platform context, see the [Node.js project](https://nodejs.org).
